# 🚀 Azka Enterprise Custom Theme & System Architecture (v10.0 Zenith Edition)


An ultra-sleek, professional, modern SaaS white-labeling suite and interface architecture engineered for **Odoo 17 Community Edition**. This module transforms the default ERP layout into a high-end enterprise platform featuring a Vercel/Stripe-inspired aesthetic.

---

## ✨ Key Features & Architecture Highlights

- **Zenith Slate Topbar**: Premium dark slate (`#0f172a`) navigation bar with primary Indigo (`#4f46e5`) accents, structured to prevent visual shadow artifacts.
- **Glassmorphic Dropdown & App Switcher**: High-contrast, clean floating pop-ups and menus engineered with crisp typography readability.
- **Stripe-Style List View Accent**: Interactive table rows featuring dynamic left-accent indicators on hover.
- **Form Sheet Elevation**: Floating sheet layout with soft micro-shadow depth and custom capsule-styled stage status badges.
- **Full System White-Labeling**: Overridden brand titles, favicon integration, and isolated login template customization.

---

## 🛠️ Stack & Technologies

- **Core ERP Engine**: Odoo 17.0 Community Edition
- **Containerization**: Docker & Docker Compose
- **Environment**: Ubuntu / WSL2 Linux
- **Frontend Customization**: CSS3 CSS Variables, QWeb XML Layout Overrides
